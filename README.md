## 1. Market Fragility, Volatility Dynamics & ML Risk Modeling  

**Skills Demonstrated:**  
Python (pandas, numpy, statsmodels, scikit-learn); GARCH volatility models; machine learning (random forest, gradient boosting); risk signal feature engineering; regime diagnostics; backtesting and interpretability analysis.

**Overview:**  
This project investigates early indicators of market fragility by analyzing volatility clustering, liquidity stress, and nonlinear regime behavior. It integrates classical econometrics (GARCH/ARCH modeling) with machine learning classifiers to identify regime shifts and potential stress conditions.

**Outcome:**  
Developed conditional volatility estimates using GARCH models and trained ML-based fragility classifiers with interpretable feature importance. Includes diagnostic stress tests, backtesting logic, and structured model documentation.  
*This analysis also supports a forthcoming research piece under **The Basel Point**, the FirstMetric research arm focusing on market structure and risk analytics.*

## 2. Credit Risk & Default Probability Modeling (ML + Validation)

**Skills Demonstrated:**  
Python (pandas, numpy, scikit-learn); logistic regression; gradient boosting (GBDT); credit-risk feature engineering; PD modeling workflows; model validation (KS/ROC/AUC); calibration curves; backtesting; drift and stability analysis; documentation and interpretability.

**Overview:**  
This project develops a probability-of-default (PD) model using both classical statistical methods and machine learning approaches. The focus is on how credit portfolios behave under different assumptions and modeling frameworks, and how uniform modeling standards can shape systemic risk.

**Outcome:**  
Built PD models with full validation: ROC/AUC, KS, calibration, confusion diagnostics, and population stability metrics. Includes backtesting logic, drift detection, and structured model documentation to reflect real-world credit modeling standards.  
*This work also informs an upcoming research note under **The Basel Point** exploring how regulatory capital models can create unintended homogeneity across financial institutions.*

This analysis is implemented across **three coordinated repositories**, each covering a different dimension of yield curve behavior and policy-cycle interpretation.

## 4. Sound the Alarm Analytics (Red Cross Project)

**Skills Demonstrated:**  
Python-based data cleaning; synthetic data generation for privacy protection; feature engineering; operational KPI design; ETL logic and workflow structuring; exploratory and statistical analysis; prescriptive modeling using machine learning.

**Overview:**  
An applied data science project supporting the Red Cross “Sound the Alarm” program, which tracks home fire safety installations and populations served across Southern California. Because the operational dataset contains sensitive personal information, a synthetic dataset was generated to replicate the statistical properties of the real dataset while ensuring full privacy preservation.

**Outcome:**  
Built a reproducible pipeline for cleaning, engineering, and modeling operational program data. Created synthesized feature fields, designed KPIs, and produced analytical insights on performance, territory trends, and community impact. Developed early-stage prescriptive ML indicators to help inform outreach prioritization and resource planning.  
*This project reflects ongoing analytics work conducted for the American Red Cross Southern California Region.*
